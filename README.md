# ExamSolve

Static multi-page competitive-exam solution library.

## Files
- `index.html` — homepage and exam navigation
- `jee.html` — JEE Main & Advanced
- `neet.html` — NEET
- `ioqm.html` — IOQM / PRMO
- `rmo-inmo.html` — RMO / INMO
- `other-exams.html` — other competitions
- `styles.css` — shared design

## Publish on GitHub Pages
Upload every file into the repository root. In Settings → Pages, select the `main` branch and `/(root)`.

Pages currently contain starter templates, not a complete set of PYQs. Add verified questions and original explanations before presenting entries as past-paper solutions.
